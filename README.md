# E-Commerce Supply Chain & Profitability Analytics
An end to end Data Analytics project showcasing data engineering, financial scenario modeling, and dynamic executive dashboarding using SQL, Excel, and Power BI.
## SQL (MySQL Workbench):
Database schema design, data cleaning, CTEs, and Window Functions (LAG(), DENSE_RANK()).
## Microsoft Excel:
Financial analysis, Pivot tables, MoM calculations, and What If Scenario Modeling.
## Power BI:
Data modeling, DAX measures, dynamic filtering, and interactive executive reporting.
# Key Business Insights
## Revenue Performance & MoM Growth:
Cleaned 9,689 raw transaction records in MySQL to build the core fact sales model, tracking monthly sales trends.
Measured revenue velocity and calculated Month over Month (MoM) performance across different sales periods.
## Customer Retention Split:
Categorized customers into Repeat vs. OneTime Buyers to track repeat purchase behavior.
Isolated top spending customers using SQL DENSE_RANK() and Excel Pivot analysis to highlight key account value.
## Geographic Revenue Distribution:
Analyzed sales across countries, identifying the United Kingdom as the primary market alongside key European regions like Germany and France.
Built dynamic region and country slicers in Power BI for cross border revenue filtering.
## Category & Product Dynamics:
Grouped item descriptions into core categories (Bags & Storage, Kitchen & Dining, Home Decor, Seasonal & Gifts) using DAX logic.
Evaluated overall completed orders against canceled order volume to identify order loss drivers.
## Financial What-If Scenario:
Modeled dynamic +10% to +15% target growth scenarios in Excel and Power BI to project potential revenue and profit lift.
